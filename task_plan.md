- **Items should not show up as Attacks** Only skills should show up as Attacks.  Items that are equipped can affect the skills potentially but they should not be listed as attacks.  For instance a character may have an item that gives them a bonus to a certain type of attack, but that item should not be listed as an attack.  The attack should be listed as a skill and the item should be listed as an item that affects that skill.
